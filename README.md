# Portal de Conteúdo — Khalid

Site estático responsivo para publicar cursos, apostilas e e-books.

## Como adicionar seus materiais
1. Coloque os PDFs na pasta `downloads/`.
2. Abra `content.js`.
3. Duplique um item e altere `type`, `title`, `description` e `file`.
4. Salve e publique a pasta inteira.

## Publicação gratuita
Este projeto pode ser publicado em serviços de hospedagem estática. Não precisa de banco de dados para a versão inicial.
